# ekko for iPhone

Open [Ekko.xcodeproj](Ekko.xcodeproj) in Xcode and run the `Ekko` scheme on an iPhone simulator or device.

The app is a local UI MVP with sample friend data. Its shield screen is an illustration only; it does not block apps or use Screen Time APIs. The visual source kit is preserved in [design-system/ekko](../design-system/ekko).
