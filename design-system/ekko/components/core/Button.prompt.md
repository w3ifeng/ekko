The ekko action button — one primary per screen, usually full-width at the bottom.
```jsx
<Button block size="lg" iconRight="arrow-right">Save my morning</Button>
<Button variant="sunrise" block>Wake my apps</Button>
<Button variant="ghost">Need access now?</Button>
```
Variants: primary, secondary, ghost, sunrise (unlock moments), night (on dark surfaces), danger (streak-ending). Sizes sm/md/lg. Press scales to .97.
